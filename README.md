# DC Standort

Screening map: what a site adds to the cost of an AI data centre in Germany, per 10 × 10 km cell.
Research prototype — master's thesis, Technical University of Munich. Feedback: i.baraia@tum.de

The whole tool is the single file `index.html` (public data of 20 September 2026, computed in the browser).
To publish a new version, replace `index.html` and commit.

Contains OpenStreetMap data © OpenStreetMap contributors (ODbL). Internet-exchange data from Packet Clearing House, CC BY-NC-SA 3.0 (non-commercial use).
